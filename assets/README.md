# Ressources publiques — application 1.0.2

Les images de `recommended/` restent nécessaires : elles sont référencées par
`home_content.json` et servent de secours lorsque les médias Steam ne sont pas
disponibles. Les anciennes versions peuvent également utiliser ces adresses.

L'actualisation des couvertures et galeries depuis Steam ne remplace pas le
catalogue éditorial des maps recommandées. Ne pas supprimer ces images sans
vérifier les références du catalogue et la compatibilité des clients existants.

`zxg_t7_icon.png` est utilisé dans le README du dépôt.

La version indiquée ici correspond à l'application ; les numéros de schéma des
fichiers JSON sont indépendants et ne doivent pas être changés en 1.0.2.
